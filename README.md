# 𓃥 白六電車訊息 (White 6 Tram Message)

**白六電車訊息** 是一個基於 **Three.js** 打造的跨平台 3D 雙軌對開電車模擬與訊息展示系統。專為高畫質廣告看板宣傳、個人化貼圖客製化與動態展示設計，支援手機與電腦瀏覽器，並具備智慧背景去背與一鍵自動錄影導出功能。

🔗 **線上體驗網址**：[https://kuochili-ops.github.io/Tram-message/](https://kuochili-ops.github.io/Tram-message/)

---

## 🌟 主要特色

### 🚊 1. 3D 雙軌對開電車模型
* **雙車對開**：包含 **White 6** 與 **Chili** 兩列對開電車，具備車頭動態專屬目的地牌與頭燈。
* **多行訊息輪播**：動態廣告看板支援多行訊息輸入，電車每跑完一趟自動切換下一行訊息。

### 🖼️ 2. 智慧圖片去背與車側排版
* **4K 超高畫質排版**：支援自訂圖片上傳、即時拖曳平移、雙指/滑鼠縮放、旋轉與亮度調整。
* **智慧連通去背 (Flood-Fill Algorithm)**：自動偵測四角背景，精準去除白底與淺灰背景，轉為純 Alpha 透明通道，完美貼合車窗而不傷主體。
* **車體對側鏡像控制**：可自由選擇是否開啟車體對側（左側）圖片的水平鏡像翻轉。

### 🎥 3. 智慧跟拍與互動操作
* **最佳觀察視角**：預設右前方微仰視角，隨時展現車頭名牌與側邊廣告看板。
* **動態跟拍與自由微調**：跟拍模式下仍支援手機觸控/滑鼠即時微調觀察角度與縮放距離，相機會保持微調後的相對距離持續平移跟隨。

### 🔴 4. 一鍵自動錄影與導出
* **全乾淨畫面錄製**：點擊「自動錄影」後，系統會自動隱藏所有 UI 控制介面與控制列。
* **完整輪播偵測**：自動重置電車並跑完整套訊息陣列（從第 1 行至最後一行）。
* **自動下載影片**：輪播結束後自動停止錄製，並將 WebM / MP4 高畫質影片自動下載至裝置。

## 🛠️ 技術架構

* **前段渲染引擎**：[Three.js](https://threejs.org/) (WebGL)
* **控制器**：OrbitControls (支援自訂相對向量跟隨演算法)
* **圖像處理**：HTML5 Canvas 2D / 智慧連通區域去背演算法
* **影片錄製**：MediaRecorder API
* **託管服務**：GitHub Pages

## 📱 使用說明

1. **上傳與調整圖片**：
   * 點擊控制面板中的 `📁 選擇 / 上傳圖片` 上傳相片。
   * 可直接在預視區用手指/滑鼠**拖曳**調整位置、**雙指/滾輪**縮放大小。
   * 可透過滑桿調整去背容差、旋轉角度與亮度，滿意後點擊 `✅ 確定更新圖片至車身`。

2. **編輯廣告訊息**：
   * 在「多行訊息」文字框內輸入宣傳標語（一行代表一班車的看板訊息）。
   * 點擊 `✏️ 更新訊息陣列` 即可同步至電車側面廣告欄。

3. **切換視角與行駛**：
   * 點擊底部 `🎥 跟拍視角` 可在「自由視角」、「跟拍 Chili」與「跟拍 White 6」之間切換。
   * 跟拍時，依然可以用手指觸控微調鏡頭角度與距離。

4. **匯出展示影片**：
   * 點擊底部 `🔴 自動錄影並下載`。
   * 控制介面將自動隱藏，電車會自動錄製完整的訊息輪播，結束後自動下載影片至您的裝置。
